# TrustVault

### Zero-Trust Secure Document Sharing Platform

## About the Project

TrustVault is a secure document-sharing platform developed to protect sensitive documents and provide controlled access to users. It follows Zero-Trust principles and uses role-based access control to prevent unauthorized access.

## Features

- Secure User Authentication
- Role-Based Access Control
- Admin and Viewer Roles
- Document Upload and Download
- Secure Document Sharing
- Access Permission Validation
- Backend Security Checks

## Technologies Used

- JavaScript
- Node.js
- HTML
- CSS
- Git and GitHub

## Project Purpose

The main purpose of TrustVault is to develop a secure document-sharing system where users can manage and share documents safely through authentication, authorization and controlled access permissions.
