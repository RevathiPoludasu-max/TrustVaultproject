# TrustVault

### Zero-Trust Secure Document Sharing Platform

## About the Project

TrustVault is a secure document-sharing platform developed to protect sensitive documents and provide controlled access to users. It follows Zero-Trust principles and uses Role-Based Access Control (RBAC) to prevent unauthorized access.

## Features

- Secure User Authentication
- Role-Based Access Control (RBAC)
- Admin, Owner and Viewer Roles
- Document Upload and Download
- Secure Document Sharing
- Access Permission Validation
- Backend Security Checks
- Controlled Document Access

## Technologies Used

- JavaScript
- Node.js
- HTML
- CSS
- Git and GitHub

## Project Purpose

The main purpose of TrustVault is to develop a secure document-sharing system where users can manage and share documents safely through authentication, authorization and controlled access permissions.

## Demo Login Credentials

The following test accounts are provided for project evaluation.

| Role | Email | Password |
|---|---|---|
| Admin | `admin@trustvault.local` | `Admin@123` |
| Owner | `owner@trustvault.local` | `Owner@123` |
| Viewer A | `viewer_a@trustvault.local` | `Viewer@123` |
| Viewer B | `viewer_b@trustvault.local` | `Viewer@123` |

### Viewer Account Explanation

- **Viewer A:** A user who is granted permission by the Owner to access a specific document.
- **Viewer B:** A separate user who is not granted permission to access that same document.

This demonstrates that Viewer A can access the shared document, while Viewer B cannot access it without permission.

*Note: These are dedicated demo accounts created exclusively for project evaluation. They contain test data and should not be used for personal purposes.*
